# PDF Extractor Worker

Aplica regras tecnicas de template sobre preview PDF estruturado.

Estrategias iniciais:

- `find_near_label`
- `fixed_bbox`
- `regex_from_text`
- `pdf_area_table`
- `pdf_column_by_x_position`
- `hierarchical_lines`

Nao executa OCR, IA, normalizacao final, regras contabeis ou conferencia.
